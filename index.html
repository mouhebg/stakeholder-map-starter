Admin mode

Your edits are saved to the map’s GitHub repository, and the site updates for everyone about a minute later. Unlock once with a GitHub key that can only write to this one repository; it stays in this browser.

  1. Open GitHub: new fine-grained token.
  2. Name it “Map admin”; set an expiry (one year is fine).
  3. Repository access: Only select repositories → .
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate, copy the key and paste it here.
Copy it from the address bar on GitHub: the two parts after github.com/
